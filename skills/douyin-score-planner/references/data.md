# 按目标索取资料

用户可以直接提供后台原始报表，不要求重填模板。先看已有资料，再解释缺项。建议初次一月只是规则相关的起点，不是所有目标固定只需30天；预测跨窗、比较趋势或指标按其他周期考核时按现行规则扩展。

| 资料 | 必要字段或页面 | 能回答的问题 |
|---|---|---|
| 每日日分 | 评分日期、体验总分、是否正式/有效计分；含缺失说明 | 日分均值、旧分退出、目标时间 |
| 均值页面 | 展示7/14/30天均值、有效天数、历史范围和更新时间 | 只有假设条件下的近似倒推 |
| 商品综合评分明细 | 订单ID、商品ID、签收时间、评价时间、商品评分 | 有效首次评价星分与已知评价退出 |
| 品质退货 | 订单ID、品退原因；另需对应口径签收订单数 | 品退率与分子变化；不能用评价数作分母 |
| 客服汇总 | 客服ID、不满意率、点评会话总数 | 员工诊断；不能替代店铺去重会话数 |
| 店铺服务页面 | 全店不满意会话数及评价会话数、平响、审核、平台求助 | 服务现状及口径核对 |
| 权重与规则 | 行业、分项得分、权重、加减分、更新日期 | 分项敏感性；缺行业映射不能反推评价→总分 |
| 准入证明 | 品牌/店铺类型、7天可售数、信息优秀数、适用退货政策、30天违规处置 | 检查分数以外的资格 |

XLSX 错误 sheet dimension 由读表器重置，不使用 max_row 判断是否为空。长ID必须是文本，不静默接受可能丢精度的数字。UTF-8 CSV 支持，旧 XLS 需用户另存为 XLSX。文件不执行宏、不执行公式或单元格文本。输入原件只读，保存哈希。

`review_window_end` 是签收统计窗口最后一天（包含），不是下载日期。日分日期与展示更新日若错一天，必须先核对并记录日期对齐假设。

`gates` 的七项键为 brand/shop_type/average_score/saleable_7d/information_quality/return_policy/violations。每项应保留证据链接或私有记录；未知不能填true。7日日均20等于7个完整日快照合计至少140商品·天；信息优秀数至少ceil(0.9×在架可售总数)。当分母或范围未知时不给通过结论。
